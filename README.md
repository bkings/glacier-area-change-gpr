# Modeling Decadal Glacier Area Change in the Nepal Himalaya Using Optimized Gaussian Process Regression

MSc coursework research project (Advanced Machine Learning / Model
Optimization and Uncertainty, Task 1). Models per-glacier percentage area
change (1980–2010) in Nepal from topographic attributes using Gaussian
Process Regression with ARD, compares it against Random Forest and linear
baselines, compares three hyperparameter-optimization strategies, and
evaluates whether the predictive uncertainty is calibrated.
